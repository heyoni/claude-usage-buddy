# claude-usage-buddy

맥 바탕화면을 돌아다니는 도트 마스코트가 **Claude Code 사용량**을 알려줍니다.
클릭하면 말풍선으로 지금 5시간 블록에서 얼마나 썼는지 보여주고, 많이 쓰면 알림도 보냅니다.

![미리보기](docs/preview.png)

> 위 그림은 표정을 한 장에 모아 찍은 것입니다. 실제로 화면에 떠 있는 마스코트는 **한 마리**입니다.

## 이런 걸 합니다

- 바탕화면 아래쪽을 느긋하게 돌아다닙니다. 드래그해서 원하는 자리에 둘 수 있습니다.
- **클릭하면 말풍선**: 현재 5시간 블록 사용률, 환산 비용, 남은 시간, 오늘/최근 7일 합계, 모델별 비중
  5초 뒤 투명해지며 사라지고, 다른 모니터나 데스크탑으로 옮겨가도 닫힙니다. 꾹 누르면 고정됩니다.
- **표정이 바뀝니다**: 여유로울 땐 멀쩡하다가, 많이 쓰면 땀을 흘리고, 안 쓰는 동안엔 잠듭니다.
- **알림**: 블록 사용률이 50 / 80 / 95% 를 넘을 때 한 번씩, 새 블록이 시작될 때 한 번
- **터미널에서도**: `python -m buddy --cli`

## 사용량은 어디서 가져오나요

Claude Code는 요청마다 `~/.claude/projects/**/*.jsonl` 에 모델명·토큰 수·시각을 남깁니다.
이 앱은 그 파일만 읽습니다. 네트워크 통신도, API 키도 필요 없습니다.

두 가지는 미리 알아두세요.

- **금액은 API 정가 환산 추정치**입니다. Pro/Max 구독으로 쓰고 있다면 실제 청구 금액이 아니라
  "같은 양을 API로 썼다면 얼마" 라는 뜻입니다.
- **사용률의 분모도 추정치**입니다. 서버가 알려주는 실제 한도는 로컬에 남지 않기 때문에,
  기본값은 *지금까지 가장 많이 쓴 5시간 블록* 을 100% 로 잡습니다.
  직접 정하고 싶으면 설정에서 `block_cost_limit` 을 지정하세요.

## 설치

macOS 전용입니다. Python 3.10 이상이 필요합니다.

```bash
git clone https://github.com/<your-account>/claude-usage-buddy.git
cd claude-usage-buddy
./install.sh
```

실행:

```bash
~/.claude-usage-buddy/venv/bin/python -m buddy
```

로그인할 때 자동으로 띄우려면:

```bash
./install.sh --autostart
```

되돌리려면 `./uninstall.sh` 를 실행하세요.

## 조작

| 동작 | 결과 |
| --- | --- |
| 클릭 | 말풍선 열기 (5초 뒤 스르륵 사라짐) / 닫기 |
| 꾹 누르기 | 말풍선 고정 — 닫을 때까지 계속 떠 있습니다 |
| 드래그 | 원하는 자리로 옮기기 (위치가 저장됩니다) |
| 우클릭 | 메뉴 — 새로고침, **크기**(아주 작게~아주 크게), 돌아다니기 끄기, 자동 실행, 설정 열기, 종료 |

## 설정

`~/.claude-usage-buddy/config.json` 을 고치고 마스코트를 다시 실행하면 반영됩니다.

```jsonc
{
  "refresh_seconds": 60,        // 사용량 다시 읽는 주기
  "block_hours": 5,             // 사용 블록 길이
  "block_cost_limit": null,     // 100% 기준 금액. null 이면 자동 추정
  "retention_days": 30,         // 트랜스크립트 보관 기간
  "notify": {
    "enabled": true,
    "thresholds": [50, 80, 95], // 이 퍼센트를 넘을 때 한 번씩 알림
    "on_block_reset": true      // 새 블록 시작을 알림
  },
  "mascot": {
    "scale": 1.0,               // 크기 배율 (우클릭 메뉴에서도 바로 바꿀 수 있음)
    "speed": 1.0,               // 걷는 속도
    "wander": true,             // false 면 제자리에 있음
    "position": null,           // 마지막 위치 (드래그하면 기록됨)
    "bubble_seconds": 5         // 말풍선이 저절로 닫히는 시간. 0 이면 안 닫힘
  }
}
```

## 구조

```
buddy/
├── usage.py      트랜스크립트 증분 색인 + 블록·일·주 집계
├── pricing.py    모델별 단가표와 비용 환산
├── sprite.py     도트 마스코트 그리기와 애니메이션
├── bubble.py     말풍선 레이아웃
├── app.py        창·이동·클릭·메뉴
├── notify.py     알림 센터 알림
├── autostart.py  LaunchAgent 등록
├── single.py     중복 실행 방지
└── cli.py        터미널 출력
tools/
└── render_preview.py   앱을 띄우지 않고 그림만 PNG 로 확인
```

첫 실행 때 `~/.claude/projects` 를 한 번 훑어 `~/.claude-usage-buddy/index.json` 에 색인을 만들고,
이후에는 파일별로 새로 늘어난 부분만 읽습니다. 수백 MB 여도 갱신은 1초 안쪽입니다.

## 알려진 제약

- macOS 전용입니다 (AppKit 을 직접 씁니다).
- 서버가 주는 실제 rate limit 잔량은 로컬에 없어서, 사용률은 어디까지나 추정입니다.
- 알림은 `osascript` 를 씁니다. 처음 한 번 알림 권한을 물어볼 수 있습니다.
